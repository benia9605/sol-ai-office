## 4. 최종 인수 테스트 (사람이 직접)

두 계정 A(운영자)·B(멤버)로 실제 기기에서.

| # | 시나리오 | 기대 |
| --- | --- | --- |
| 1 | A 가 일정 등록 | B 에게 `📅 새 일정` 푸시 · 피드에 등장 · 클릭 시 `/meetings/:id` |
| 2 | B 가 지각 보고 (사유 입력) | A 에게만 `⏰ 지각 알림` · 피드에 사유까지 |
| 3 | A 가 회의록 작성 + B 에게 할일 배정 | B 에게 `📝 새 회의록` + `📝 새 할일` 2건 |
| 4 | B 가 할일 상세에서 본문 작성 + 파일 첨부 + 「수정 + 완료」 | A 에게 `✅ 할일 완료` · 피드 갱신 · 첨부 뷰어 열림 |
| 5 | A 가 그 할일에 댓글 | B 에게 `💬 새 댓글` |
| 6 | B 가 그 댓글에 **답글** | A 에게 `↳ 내 댓글에 답글` (다른 멤버에겐 안 감) |
| 7 | A 가 좋아요 | B 에게 `👏 좋아요` (단, 운영자 토글에서 like 가 켜져 있을 때만) |
| 8 | B 가 알림 설정에서 「댓글」 끄기 → A 가 다시 댓글 | 푸시 안 옴 · 피드에는 남음 |
| 9 | B 가 홈 방문 | 「확인이 필요한 일」에 미완료 할일 · 미응답 안건 |
| 10 | B 가 「내 활동」 방문 | 자기가 만든 글·할일·회의록이 종류별로 보임 |
| 11 | 알림을 눌러 착지 → 뒤로가기 | 목록으로 정상 복귀 (팝업 UI 였다면 여기서 깨진다) |
| 12 | 모바일 세로 · 가로 | **가로 스크롤이 전혀 없다** |

## 5. 자주 나는 사고 8가지

| 증상 | 원인 |
| --- | --- |
| 자기 행동 알림을 자기가 받는다 | `actor_id` 누락 |
| 알림이 전원에게 간다 | `target_user_ids` 누락 |
| 알림을 눌러도 이동 안 함 | `url` 이 실제 라우트가 아님 (팝업 UI) |
| 편집 저장할 때마다 "완료했어요" | `wasDone` 전환 감지 없음 |
| 회의록 수정하면 할일 완료 상태가 날아감 | 전부 삭제 후 재생성. `syncTasksForNote` 를 써라 |
| 오늘 마감인데 아침부터 「지연」 | `startOfDay()` 없이 시각까지 비교 |
| 일정 시간이 9시간 밀림 | `iso.slice(0,16)` 로 datetime-local 채움 |
| 댓글은 달리는데 피드/알림이 없다 | 페이지에서 supabase 직접 호출 (원칙 2 위반) |
