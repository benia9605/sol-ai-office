> **용도:** GPT 검증(설계)을 받아 구현한 **AI 직원 5명 + CEO 브리핑** 전체를 한 문서로 정리.
> 대표님이 **이 문서 하나 보면서 순서대로 클릭해 확인**할 수 있게 만든 테스트 가이드.

## 0. 큰 그림 (GPT가 확정한 방향)

> **AI Office = "AI와 대화하는 앱"이 아니라, AI가 회사 데이터를 읽고 자동으로 일하는 운영 시스템.**
> 긴 대화가 필요한 생산(전략·상세페이지·콘텐츠 기획·광고·디자인)은 **GPT 프로젝트**에서,
> 데이터를 계속 읽어야 하는 자동 업무(분석·운영·모니터링·일정·CS)는 **AI Office 직원**이.

**앱에서 실사용화한 직원 5명:**
| 직원 | 한 줄 역할 | 데이터 소스 |
|------|-----------|-------------|
| 🧭 운영매니저 | 전 직원 신호 취합 → "오늘 볼 것" (CEO 브리핑 편집장) | 아래 4명 + 할일·일정·승인 |
| 📊 분석가 | 매출·콘텐츠 성과 집계·해석·이상치 | sales_daily · content_metrics |
| 🗓 일정비서 | 촬영/편집/발행·마감 스케줄러 | tasks · schedules · content_items |
| 💬 CS | 문의 분류·답변초안·FAQ | tickets · cs_faq |
| 📡 모니터링 | 경쟁사·키워드 트렌드 레이더 | watch_items |

**공통 원칙:** 숫자·집계는 **코드로 계산**(API 키 없이도 화면에 실데이터가 뜸). "원본은 기존 테이블, 직원 리포트는 해석."

## 2. 테스트 순서 (이대로 클릭하면 다 확인돼요)

### ✅ STEP 1 — 대시보드 CEO 브리핑 (제일 중요)
1. 오피스(시목) → **대시보드**.
2. 하루 운영 흐름 아래 **🧭 CEO 브리핑** 카드 → **‘브리핑 생성’** 클릭.
3. 확인 포인트:
   - **① 오늘 한 줄**(신호등 🟢🟡🔴) → **② 대표가 볼 것 TOP3** → **③ 매출/콘텐츠 한 줄** → **💬 문의 / 📡 트렌드 한 줄** → **④ 운영 4칸(지연·오늘마감·미배정·승인대기)** → **⑤ 오늘 할 일** → **💡 조언**
   - **매출 카드에 "월 목표 설정"** → 3000 입력 → **달성률(%)** 이 뜨는지.
4. **대시보드는 AI를 직접 부르지 않고, 저장된 브리핑 JSON만 그림.** (운영매니저 산출물 = Source of Truth)

### ✅ STEP 2 — 분석가 (📊)
1. AI 직원 → **분석가** (없으면 채용).
2. 상단 **📊 실데이터 스냅샷** 확인:
   - **기간 토글 7·30·90일** → 누르면 숫자 바뀜. **매출에 직전기간 대비 ▲▼%**.
   - **핵심 KPI 5**: 매출·객단가·저장률·공유율·팔로워순증.
   - **🧪 발견된 시목 공식**: 콘텐츠 성과가 쌓이면 유형별 저장률 + **표본 n 라벨**(데이터부족<3 / 초기신호3~5 / 경향6~10 / 패턴>10).
   - **이상치**: 매출 급변 시 🔴🟡, 잘된 유형 🟢.
> ⚠️ 저장률·공유율·시목 공식은 **콘텐츠 성과(24h/72h/7d)** 를 입력해야 채워져요 → 콘텐츠 메뉴에서 발행 후 성과 입력.

### ✅ STEP 3 — 일정비서 (🗓)
1. AI 직원 → **일정 비서** (없으면 채용).
2. **🗓 오늘 실행 계획** 확인:
   - 단계 카운트(오늘 일정·촬영·편집·발행) · **오늘 타임라인**(일정·발행예정·마감 시간순) · **충돌 감지**(지연·발행 미완성·과부하) · **빈 시간**(09~19시) · **이번 주(월~일)**.
> ⚠️ 콘텐츠 단계 카운트는 콘텐츠에 **발행 예정일**이 있어야 잡혀요.

### ✅ STEP 4 — CS (💬)
1. AI 직원 → **CS 응대** (없으면 채용).
2. **💬 문의 관리** → **티켓** 탭:
   - 고객 문의를 붙여넣고 **‘＋ 분류·추가’** → **유형·긴급도·감정·승인필요** 자동 분류.
   - (예: "도마가 깨져서 왔어요 환불해주세요" → **환불·긴급·부정·승인 필요**)
3. **FAQ** 탭 → **‘🌱 시목 FAQ 채우기’** → 원목·도마·가구·배송·A/S **20개** 자동 등록.
4. 🔗 **긴급 문의를 넣으면 STEP 1 대시보드 브리핑 TOP에 "🔴 긴급 CS 문의 N건"** 으로 올라옴 (직원 연결!).

### ✅ STEP 5 — 모니터링 (📡)
1. AI 직원 → **경쟁사 감시** (모니터링).
2. **📡 트렌드 레이더**:
   - **‘🌱 시목 시드’** → 경쟁사 6곳(직접/인접/지향) + 키워드 13개(제품/생활욕망/감성/포맷) 자동 등록.
   - **키워드** 탭 → 각 키워드 **🎬** → 콘텐츠 아이디어로 전환(콘텐츠 메뉴에 "[트렌드] … 시목 버전" 아이디어 생김).

### ✅ STEP 6 — 운영매니저 (🧭, 편집장)
1. AI 직원 → **운영 매니저** (없으면 채용).
2. **🧭 CEO 브리핑 편집장** 패널 → **‘브리핑 생성’** → 전 직원 신호 취합해 헤드라인·TOP3·운영 4칸·조언. **= 대시보드에 그대로 반영.**

### ✅ STEP 7 — 할일 페이지 개편
1. 오피스 → **할일**.
2. **[일별]** — 날짜 **‹ ›** 로 하루씩 넘김 + **오늘로** / 순서: **지연(오늘 이전 미완료) → 할 일 → 완료**.
3. **[전체]** — 진행/완료 2열. **[캘린더]** — 주간 그리드 + 아젠다(개인 공간과 동일).
4. **＋ 할일 추가** → 날짜가 **기본 오늘**로 채워짐(수정 가능).

### ✅ STEP 8 — 멤버 / 버그 픽스
- **멤버** 메뉴 → 본인 행 **✏️** → 닉네임 설정.
- 모바일에서 **하단 메뉴바 아이콘**이 바 안에 잘 들어오는지(튀어나옴 픽스).

## 3. 무엇을 어떻게 만들었나 (기술 요약)

### 데이터 레이어 (신규 테이블 3개 · 마이그 033~035)
| 마이그 | 테이블 | 용도 |
|--------|--------|------|
| 033 | `office_briefings` + `workspaces.monthly_sales_target` | CEO 브리핑 JSON 저장 + 월 목표(수동) |
| 034 | `tickets` + `cs_faq` | CS 문의 티켓 + FAQ |
| 035 | `watch_items` + `watch_snapshots` | 트렌드 레이더 워치리스트 |
> RLS는 전부 `my_workspace_ids()` (오피스 멤버만). idempotent. 원본은 기존 테이블 — 직원 리포트는 해석만.

### 서비스 (계산·집계 로직)
| 파일 | 역할 |
|------|------|
| `analytics.service.ts` | `fetchWorkspaceAnalytics`(대시보드·브리핑용) + `fetchAnalystInsights`(기간·이상치·시목 공식) |
| `officeBriefing.service.ts` | `buildBriefingJson` — 매출·콘텐츠·할일·일정·승인·**CS·모니터링** 취합 → CEO 브리핑 계약. `generateBriefing`/`fetchLatestBriefing` |
| `schedulerInsights.service.ts` | 타임라인·충돌·빈시간·주간 |
| `cs.service.ts` | `classifyTicket`(규칙 분류) + 티켓/FAQ CRUD + `seedSimokFaq` |
| `monitor.service.ts` | 워치리스트 CRUD + `seedSimokWatchlist` + `watchToContentIdea` |

### UI (직원 상세 전용 패널)
- `views.tsx` → `BriefingPanel`(대시보드 CEO 브리핑), 할일 `TodosView`(일별/전체/캘린더).
- `StaffView.tsx` → 타입별 패널: `AnalystDataPanel`·`SchedulerDataPanel`·`CSDataPanel`·`MonitorDataPanel`·`OpsDataPanel`.
- 디자인: 무지 모던톤(라이트 대형 헤드라인·네모 카드), 신호등 색상.

### 직원끼리 연결 (GPT가 강조한 핵심)
```
💬 CS "긴급 문의"  ─┐
📊 분석가 "성과"    ├─→  🧭 운영매니저(취합·우선순위) ─→ CEO 브리핑 JSON ─→ 📊 대시보드
📡 모니터링 "트렌드"┘                                              ↑ 대표는 이것만 보면 됨
🗓 일정비서 "오늘 계획"
```
